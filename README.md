# Evy Shen — personal site

A single-page portfolio. Everything (styles, script, photos) is inside `index.html`, so there is nothing to build.

## Editing
- **Work, projects, writing:** copy one `<li>` in the matching list in `index.html`. Project years go in the empty `yr` span.
- **Hover photos:** edit `GALLERY` in the script (each entry has a caption and an image).
- **The pond picture:** drawn in the script; search for "still pond". `STOPS` sets the sky colors through the day.
- **LinkedIn:** replace the placeholder link in the footer (marked `TODO`).

## Publishing with GitHub Pages
Settings → Pages → Deploy from a branch → `main` / root. The site will be at `https://<username>.github.io/<repo>/`.
